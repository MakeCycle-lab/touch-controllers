# Touch Controllers

Reusable touch controller boards, shared across all display projects in the [MakeCycle-lab](https://github.com/orgs/MakeCycle-lab/repositories) organization.

A touch controller converts a device's proprietary touch matrix into a standard interface (USB / I2C), so any mainboard can use it.

| Board | Chip | Function | Status |
| :--- | :--- | :--- | :--- |
| **[ch554](ch554/)** | CH554 | USB HID capacitive touch (pairs with GT9110-based adapters) | ✅ Released |

## 🔗 Used By

* [edp-monitor-diy](https://github.com/MakeCycle-lab/edp-monitor-diy) — iPad screen adapters with GT9110 touch output
